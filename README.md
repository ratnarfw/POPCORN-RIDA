# POPCORN-RIDA
POPCORN RIDA (Pojok Pustaka Corner Riset dan Inovasi Daerah) ialah perpustakaan digital bidang RIDA yang menghimpun &amp; menyebarluaskan hasil penelitian, menyediakan akses pengetahuan yang mudah, cepat, &amp; terintegrasi bagi masyarakat, peneliti, akademisi, ASN &amp; OPD guna referensi pengembangan wawasan perencanaan pembangunan berbasis bukti.
